# تصميم: المراقبة الخارجية للموقع (الجزء 4)

- **التاريخ:** 2026-10-27
- **الحالة:** معتمد من صاحب المشروع، بانتظار خطة التنفيذ
- **يبني على:** [الجزء 1](2026-10-26-multi-tenant-core-design.md) و[الجزء 2](2026-10-26-log-ingestion-design.md) و[الجزء 3](2026-10-26-webhook-approval-design.md)

## 1. الهدف

أن يضيف صاحب المنشأة رابط موقعه، فتراقبه المنصة من الخارج بلا أي تثبيت على خادمه: هل الموقع يعمل وبأي سرعة، وما ثغرات ترويسات الأمان فيه، وهل توجد ملفات حساسة مكشوفة للعامة. ويحصل على **درجة أمان** مفهومة، و**إصلاح جاهز** لكل ملاحظة، و**تنبيه وحادثة** عند المشاكل الخطيرة.

**خارج النطاق:** فحص شهادة TLS وإعدادات HTTPS (لم تُختر)، فحص المنافذ، فحص الثغرات النشط، تحقيق المحلل الذكي في حوادث المراقبة (لا عنوان مهاجم لحظره).

## 2. المواقع والتحقق من الملكية

- صفحة جديدة «المراقبة»؛ حتى **5 مواقع** لكل منشأة، رابط كامل `http(s)://host[:port]` يُطبَّع إلى الأصل (بلا مسار).
- **العناوين الداخلية:** موقع يُحل إلى عنوان داخلي/محلي يُرفض ما لم يكن `ALLOW_PRIVATE_TARGETS=true` (افتراضيًا `true` محليًا ليعمل موقع العرض على نفس الجهاز، و`false` في أي نشر). يُفحص عند الإضافة وقبل كل طلب.
- **رمز تحقق لكل موقع:** `pc-verify-<32 حرفًا عشوائيًا>`، والتحقق بإحدى طريقتين:
  - ملف `<الموقع>/.well-known/pc-verification.txt` يحوي الرمز (يُقبل إن احتوى النص الرمز بعد إزالة المسافات)؛
  - سجل DNS من نوع TXT على `_pc-verify.<المضيف>` قيمته الرمز (عبر مكتبة `dnspython`؛ مكتبة Python القياسية لا تقرأ TXT).
- زر «تحقّق» يجرّب الطريقتين ويسجّل وقت التحقق.

| الفحص | قبل التحقق | بعده |
|---|---|---|
| التوفر وزمن الاستجابة (طلب واحد للرئيسية) | ✓ | ✓ |
| ترويسات الأمان | — | ✓ |
| الملفات الحساسة المكشوفة (~10 طلبات خفيفة) | — | ✓ |

## 3. الجدولة

- **التوفر:** كل 5 دقائق. **الترويسات والملفات:** يوميًا (بعد التحقق مباشرة أول مرة).
- **«افحص الآن»:** فحص كامل فوري، بحد مرة كل دقيقة لكل موقع (429).
- **المجدول:** خيط خلفي كل 15 ثانية يمر على مواقع المنشآت ويشغّل المستحق في مجمّع من 4 عمّال، حتى لا يعطّل موقع بطيء غيره.
- **الطلبات:** `User-Agent: PredictiveCyber-Monitor/1.0`، مهلة 10 ثوانٍ، حتى 5 تحويلات (يُعاد فحص العنوان الداخلي لكل تحويل)، وقراءة 256KB كحد أقصى من الجسم.

## 4. الفحوص

### التوفر

- `GET` للرئيسية. **«متعطل»:** فشل اتصال أو مهلة أو حالة 5xx. **«بطيء»:** أكثر من 3 ثوانٍ.
- **فحصان متتاليان متعطلان** ← حادثة `site_down` (critical) وتنبيه. **3 فحوص بطيئة متتالية** ← تنبيه `site_slow` (medium) بلا حادثة. **عودة الموقع** ← تنبيه عودة وإغلاق الحادثة تلقائيًا.
- يُعرض التوفر خلال 24 ساعة (نسبة الفحوص الناجحة) وآخر زمن استجابة.

### ترويسات الأمان (من رد الرئيسية)

| الملاحظة | الخصم |
|---|---|
| لا `Content-Security-Policy` | 15 |
| لا `Strict-Transport-Security` (لمواقع HTTPS فقط) | 10 |
| لا `X-Frame-Options` ولا `frame-ancestors` في CSP | 10 |
| ملفات تعريف ارتباط بلا `Secure` (في HTTPS) أو بلا `HttpOnly` | 10 |
| لا `X-Content-Type-Options: nosniff` | 5 |
| لا `Referrer-Policy` | 5 |
| لا `Permissions-Policy` | 5 |
| كشف إصدار الخادم في `Server` (رقم إصدار مثل `nginx/1.18.0`) | 5 |
| كشف `X-Powered-By` | 5 |

### الملفات الحساسة المكشوفة

- المسارات: `/.env`، `/.git/config`، `/.git/HEAD`، `/backup.zip`، `/db.sql`، `/phpinfo.php`، `/server-status`، `/wp-config.php.bak`، `/.DS_Store`.
- **فخ الإنذار الكاذب:** مواقع كثيرة (SPA) ترد 200 بالصفحة الرئيسية لأي مسار. لذلك:
  - يُطلب أولًا مسار عشوائي غير موجود كخط أساس (حالته وبصمة جسمه).
  - الملف «مكشوف» فقط إذا ردّ 200 **وطابق بصمة محتواه**: `.env` ← سطر `KEY=value` (اسم بأحرف كبيرة)؛ `.git/HEAD` ← يبدأ بـ `ref: refs/`؛ `.git/config` ← `[core]`؛ `phpinfo.php` ← `phpinfo()`؛ `server-status` ← `Server Status`؛ الملفات الثنائية والنسخ الاحتياطية (`backup.zip`، `db.sql`، `.DS_Store`، `wp-config.php.bak`) ← نوع محتوى غير HTML وجسم يختلف عن خط الأساس.
- كل ملف مكشوف: خصم 40، وحادثة `exposed_file` — **critical** لـ `.env` و`.git`، و**high** لغيرها — وتنبيه فوري.

### الدرجة

تبدأ من 100 وتُطرح الخصومات (حدها الأدنى صفر): A ≥ 90، B ≥ 80، C ≥ 70، D ≥ 60، وإلا F. تُعرض مع قائمة الأسباب. لا تُحسب قبل أول فحص للترويسات (تُعرض «بانتظار التحقق»).

### نصائح الإصلاح

لكل ملاحظة: شرح عربي للخطر، وسطر إصلاح جاهز لـ **Nginx** (`add_header ... always;` أو `server_tokens off;` أو `location ~ /\. { deny all; }`)، والمكافئ لـ **Apache** (`Header always set ...` أو `ServerTokens Prod`).

## 5. الحوادث والتنبيهات

- المشاكل الخطيرة تُسجَّل في **نفس قائمة الحوادث** (جدول `incidents`/`alerts` من الجزء 2)، بمصدر `monitor` ونوعَي `site_down` و`exposed_file`، و«العنوان» فيها هو مضيف الموقع.
- **لا تحقيق تلقائي للمحلل** في حوادث المراقبة: لا عنوان مهاجم لحظره، والمطلوب إصلاح. فتح الحادثة من «منشأتي» ينقل لبطاقة الموقع في «المراقبة».
- **إغلاق تلقائي** عند الحل: عودة الموقع، أو عدم انكشاف الملف في الفحص التالي.
- **حدث جديد `monitor.alert`** عبر Webhook وTelegram: `{site, kind: down|recovered|slow|exposed_file, severity, detail, fix}`. المنفّذ المرجعي يقبله بـ `ignored`.

## 6. التخزين

في `tenant.db` الخاص بالمنشأة:

- `sites(id, url, token, verified_at, verify_method, created_at, last_avail_at, last_deep_at, last_manual_at, down_streak, slow_streak, incident_id)`
- `checks(site_id, ts, kind, ok, status, ms, detail)` — يُحتفظ بها 7 أيام.
- `findings(site_id, key, severity, deduction, detail, fix, first_seen, last_seen, resolved_at)`

## 7. الواجهة

صفحة «المراقبة» في قائمة «منشأتي»: نموذج إضافة موقع، وبطاقة لكل موقع فيها:
- حالة التحقق مع التعليمات (الرمز، مسار الملف، سجل DNS) وزر «تحقّق»؛
- الدرجة وحرفها والأسباب؛
- التوفر خلال 24 ساعة وآخر زمن استجابة وحالة «يعمل/متعطل»؛
- الملاحظات، ولكل منها إصلاح قابل للفتح والنسخ؛
- زرا «افحص الآن» و«حذف».

## 8. موقع العرض (`demo_site.py`)

خادم محلي صغير يحاكي متجرًا بثغرات مقصودة: بلا ترويسات أمان، `Server: nginx/1.18.0`، و`/.env` وهمي، ويرد 200 لأي مسار آخر (SPA) ليظهر أن الفحص لا ينخدع. يدعم `--token` لملف التحقق، ونقطتي تحكم محليتين `/__down` و`/__fix` لإظهار التعطل والعودة والإصلاح أمام اللجنة.

## 9. الاختبارات (pytest)

- **التحقق:** بالملف (خادم HTTP محلي في الاختبار)، وبـ DNS عبر محلل وهمي؛ رمز خاطئ يفشل.
- **الترويسات والدرجة:** موقع محلي بلا ترويسات ← الملاحظات المتوقعة والدرجة؛ موقع مكتمل الترويسات ← A.
- **الملفات:** موقع SPA يرد 200 لكل شيء ← لا إنذار كاذب؛ `.env` حقيقي ← `exposed_file` critical.
- **السلوك:** لا فحص ملفات أو ترويسات قبل التحقق؛ تعطلان متتاليان ← حادثة وتنبيه، والعودة تغلقها؛ حد «افحص الآن»؛ عنوان داخلي مرفوض عند `allow_private_targets=False`؛ حد 5 مواقع؛ العزل بين المنشآت (404).
- **الاختبارات الحالية (144)** تبقى ناجحة.
